# CLIP Text-Based Image Search

This project uses OpenAI CLIP to search images using natural language.

## Features

- Text-based image search
- CLIP image and text embeddings
- Cosine similarity
- Streamlit web interface
- Multiple image search results

## Technologies

- Python
- Streamlit
- PyTorch
- Hugging Face Transformers
- OpenAI CLIP
- Pillow

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
